# VIT Relative Grade Estimator

A Chrome extension that enhances the VIT VTOP marks page by displaying
relative grade statistics such as mean, standard deviation, grade ranges,
and estimated grade based on anonymous, student-submitted marks.

## How it works
- Runs only on the VIT VTOP marks page
- Extracts the logged-in student's marks locally
- Sends only anonymized academic data (no names, no passwords)
- Displays relative grading insights below each theory course

## Privacy
- No personal information is collected or stored
- No credentials, cookies, or session data are accessed
- Data is used solely for academic grade estimation
